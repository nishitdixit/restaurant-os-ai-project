# SEO Spec

## Goal

Produce technically strong, accurate, indexable storefront pages.

## Requirements

- metadata templates;
- canonical;
- sitemap;
- robots;
- structured data;
- semantic HTML;
- product/category crawl paths;
- image optimization;
- noindex controls for non-public utility pages.

## Acceptance

A newly published merchant site has complete metadata and sitemap entries without manual code changes.
