# Public Web Store

## Goals

- fast;
- mobile-first;
- visually credible;
- accessible;
- SEO-ready;
- direct-order optimized.

## Core pages

- home;
- menu;
- category;
- product;
- offers;
- service area;
- contact/about;
- checkout;
- order confirmation;
- order tracking.

## UX hierarchy

Primary CTA: `Order Direct`

Secondary actions may include WhatsApp and supported marketplace links.

## Conversion principles

- make availability visible;
- show price before interaction where possible;
- minimize checkout fields;
- preserve cart state;
- explain delivery fee early;
- make payment outcome clear;
- support recovery from failure;
- make reordering easy.

## Theme system

Tenant-specific branding should be data/configuration. Components are shared.

## Content safety

Merchant-supplied content must not be allowed to inject arbitrary scripts or unsafe HTML.
