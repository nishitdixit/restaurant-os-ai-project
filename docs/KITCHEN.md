# Kitchen Operations

## MVP

Admin order board is the first kitchen tool.

Columns:

`New | Accepted | Preparing | Ready | Packed | Dispatched`

## KDS direction

A dedicated kitchen display later simplifies noisy order operations.

Required future capabilities:

- sound/new-order indicator;
- item grouping;
- priority;
- prep timer;
- promised time;
- station routing later;
- workload visibility.

## Capacity

Future kitchen-capacity controls may:

- extend estimated preparation time;
- temporarily pause order intake;
- limit delivery slots.

Do not silently change customer promises. Operational changes should be visible and auditable.
