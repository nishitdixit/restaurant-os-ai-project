# UX Principles

## 1. One obvious next action

Every major screen should have a clear primary action.

## 2. Reduce owner anxiety

Orders, payments, delivery and stock should have visible state and timestamps.

## 3. Prefer bulk operations

Restaurant owners often repeat the same action across many menu items.

## 4. Design for mobile customer, desktop owner

Customer checkout is mobile-first. Admin can be desktop-first but must remain usable on smaller screens.

## 5. Empty states teach

Explain what the user can do next rather than displaying blank tables.

## 6. Error recovery is part of the flow

Payment failure, out-of-stock item, delivery-zone mismatch and provider outage need clear recovery actions.

## 7. Don't hide operational truth

If an order is delayed, the admin should see why; if the customer is affected, communicate appropriately.

## 8. Progressive disclosure

Basic workflows are simple. Advanced controls live behind expandable configuration.

## 9. Consistency over novelty

Reuse patterns across catalog, promotions, orders and settings.
