# Product Scope

## Release labels

### MVP

Prove direct digital commerce and basic restaurant operations for one real pilot while preserving multi-tenant architecture.

### V1

Make the product operationally valuable to recurring paying tenants.

### V2

Add deeper automation, retention and integrations.

### Future

Expand to advanced inventory, multi-brand operations, AI intelligence, broader POS and procurement capabilities.

## MVP included

- multi-tenant core;
- merchant onboarding;
- storefront;
- catalog;
- search;
- cart;
- checkout;
- delivery area rules;
- payments;
- order lifecycle;
- basic admin;
- stock availability;
- offers;
- customers;
- notifications;
- manual delivery dispatch;
- basic analytics;
- SEO foundation;
- admin roles;
- audit log.

## Explicitly deferred

- full recipe/BOM inventory;
- purchase orders and supplier management;
- accounting and GST filing workflows;
- payroll;
- hardware POS;
- tables/reservations;
- advanced loyalty;
- automated CRM journeys;
- real-time aggregator synchronization;
- automatic Porter/local vendor booking;
- native customer mobile app;
- full rider fleet management;
- multi-brand shared inventory;
- advanced forecasting;
- generative AI decision automation.

## Feature admission rule

A new MVP feature is accepted only when all are true:

1. it solves a demonstrated pilot pain;
2. it has a clear user outcome;
3. it does not require a large unrelated subsystem;
4. it does not compromise tenancy or domain integrity;
5. the team can test it deterministically.
