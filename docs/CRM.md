# CRM and Customer Ownership

## Core idea

Direct orders create first-party customer relationships that the merchant can use for retention, subject to privacy and consent requirements.

## Customer profile

- identity;
- contact information;
- addresses;
- first/last order;
- order count;
- lifetime gross/net value as defined;
- favorite products;
- coupon history;
- last activity;
- consent/preferences.

## Segments

MVP simple filters:

- new customers;
- repeat customers;
- inactive for N days;
- total spend threshold;
- order count threshold.

V1+: behavior segments, product affinity, campaign engagement.

## Customer timeline

Show:

- orders;
- refunds;
- coupons;
- campaigns;
- support notes where permitted.

## Privacy

Customer data access is role-limited. Marketing use must respect consent/eligibility.
