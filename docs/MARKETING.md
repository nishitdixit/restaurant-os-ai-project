# Marketing and Promotions

## Promotion engine

Use structured rules rather than hard-coded coupons.

### Condition examples

- customer is new;
- cart total >= X;
- contains product/category;
- code equals X;
- date/time window;
- customer segment.

### Benefit examples

- fixed discount;
- percent discount;
- free delivery;
- free item;
- future loyalty credit in later versions.

## Campaign model

`Audience -> Offer -> Message -> Channel -> Attribution`

## MVP

- coupon creation;
- start/end time;
- usage limit;
- customer eligibility;
- redemption tracking.

## V1

- saved customer segments;
- WhatsApp campaign integration;
- campaign analytics;
- referral program.

## V2

- automated win-back;
- lifecycle journeys;
- personalized offers;
- experimentation.

## Guardrail

The platform should optimize for incremental profitable orders, not raw coupon redemption.
