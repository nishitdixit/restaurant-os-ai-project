# Contribution Guide

## Before coding

Read task -> spec -> business rules -> relevant architecture.

## During coding

Prefer small changes, tests and existing patterns.

## Before PR

Run lint, typecheck, unit/integration tests and relevant E2E tests.

## PR description

Include:

- outcome;
- scope;
- tests;
- migrations;
- risks;
- rollout/rollback;
- screenshots for UI changes.

## AI-generated code

AI-generated code is treated exactly like human-written code: it must meet the same security, testing and maintainability standards.
